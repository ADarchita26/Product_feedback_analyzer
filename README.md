# 🛍️ Product Feedback Analyzer

## 🚀 Features

- Analyze product reviews
- Identify sentiment: Positive, Negative, or Neutral
- Give a rating from 1 to 5
- Identify the main review theme
- Store analyzed reviews in SQLite

## 🛠️ Technologies Used

- Python
- FastAPI
- Streamlit
- Google Gemini API
- SQLite
